# 01 — Платформа: що ми успадковуємо готовим

Головна причина взяти саме Neptune — не характеристики плати, а те, що
**місяць bring-up уже оплачений** проектом `sdr-ground`. Нижче — що саме
переходить сюди як факт, а не як надія.

## 1.1 Залізо [V] — перевірено на платі в sdr-ground

| Вузол | Що встановлено | Як доведено |
|---|---|---|
| SoC | **XC7Z020** (CLG400 [?]) | JTAG IDCODE `0x23727093` |
| DDR3 | **1 ГБ, 32-бітна шина** | свій образ бутиться, `free` показує гігабайт |
| Трансівер | **AD9361** (не AD9363!) | `PRODUCT_ID 0x0A`, `ad9361_probe` на нашому бітстрімі |
| RF | **2 RX + 2 TX**, спільний гетеродин → **канали когерентні** | sdr-ground/27: обидва RX приймають, зняття антени RX2 змінює лише RX2 |
| Семплрейт | 30.72 MSPS підтверджено живим | `LO=2436999998 fs=30720000` |
| Ethernet | **Гігабіт чистий**: 332 Мбіт/с плата→хост, 524 хост→плата | `iperf`-клас замір, sdr-ground/14-M.5 |
| QSPI | W25Q256, 32 МБ | `sf probe` |
| Debug | бортовий FT2232: JTAG + UART на дальньому USB-C | працює, зовнішній адаптер не потрібен |
| Boot | свій образ із microSD, ~45 с до сервісу | sdr-ground |

**Пінаут AD9361 розв'язаний** і лежить у
`sdr-ground/vendor/neptunesdr-xdc/p210-readback-constr.xdc`. Це найдорожчий
артефакт усього проекту: шість відкритих пінаутів (включно з тим, що ходить як
«neptunesdr» і з `openwifi/neptunesdr_new`) **не збігаються з платою** —
відрізняються `spi_csn`, `enable`, `txnrx`.

> [!] Якщо колись беремо чужий HDL під «neptunesdr» — у ньому буде неправильний
> SPI. Шина даних збігається, керування ні. Ціна необізнаності — тиждень
> (sdr-ground/23.3).

## 1.2 Що з цього критично саме для mesh

| Факт | Чому це важливо тут |
|---|---|
| **2×RX когерентні** | Двоелементна адаптивна решітка → нуль у напрямку завади, 20–30 дБ. Головна фіча, якої немає у wy-lora (Pluto 1R1T) |
| **2×TX** | Другий TX = лабораторний джамер і генератор для вимірювань, без другої плати |
| 1 ГБ DDR | Буфери IP-черг, повні захвати IQ для офлайн-аналізу |
| Гігабіт | На землі: вузол — самодостатній мережевий пристрій. У повітрі не потрібен |
| 53k LUT / 220 DSP / 140 BRAM | Стеля дизайну. **DSP — зв'язуючий ресурс**, див. 09 |
| Бортовий JTAG+UART | Ітерація бітстріму в RAM без чіпання QSPI; критично на 3 платах |

## 1.3 Що на цій платі **не перевірялось** [?] — задачі фази 0

`sdr-ground` — приймач. Усе, що стосується передачі і часу, там не чіпали:

| Що | Чому відкрито | Як перевіряти |
|---|---|---|
| **TX-тракт** | Жодного рядка в sdr-ground: «TX-тракт плати не використовуємо» | DDS-тон з PL → `TX1` → спектроаналізатор / другий Neptune на RX |
| Потужність на виході AD9361 | Паспорт ~+7 дБм, на платі з обв'язкою — [?] | Замір по діапазону, бо PA треба узгоджувати з реальним входом |
| TDD-перемикання (ENSM) | Не задіяне | Час переходу RX↔TX на залізі, джиттер |
| FastLock | Не задіяний | Реальний час перестроювання на стрибках у сотні МГц |
| **Зовнішній опорний генератор** | На платі свій TCXO ~40 МГц. Чи можна завести 10 МГц від атомника — невідомо | Знайти TCXO на платі, перевірити чи є VCTCXO-керування / майданчик для інжекції |
| PPS у PL | Не задіяне | Вільний GPIO → PL-таймер, замір джиттера мітки |
| Теплові режими під TX | Приймач гріється менше | Прогін із 50% duty cycle TX у закритому корпусі |
| Корпус FPGA, eFUSE-AES | Не закрито в sdr-ground | Лишається відкритим і тут |

> [!] **Опорний генератор — ключова розвилка фази 0.** Атомний еталон дає
> користь двома різними шляхами, і вони вимагають різного заліза:
>
> | Шлях | Що потрібно | Що дає |
> |---|---|---|
> | **A. PPS у PL** (дешево) | один GPIO, кабель | Час TDMA-сітки. Частота RF лишається від бортового TCXO |
> | **B. 10 МГц в AD9361** (треба мод) | інжекція опори замість TCXO | Час + **частотна точність RF** (±1e-11 проти ±1e-6) |
>
> Шлях A достатній для TDMA і працює одразу. Шлях B додатково знімає
> частотну невизначеність ±2 кГц на 2 ГГц, що прямо спрощує carrier recovery
> і дозволяє вузькі канали. Робимо A у фазі 0, B досліджуємо паралельно.

## 1.4 Три плати: розподіл ролей у PoC

| Плата | Роль | Обв'язка |
|---|---|---|
| **N1** | Наземна станція | Атомний еталон + PPS, PA, широкосмугова направлена антена (Вівальді / LPDA), LNA, 2 антени для нуль-формування |
| **N2** | Борт A (релей) | FEM (PA+LNA+switch), широкосмугова омні, UART до польотника |
| **N3** | Борт B (дальній) | Те саме, що N2 |
| *(N0)* | Плата з `sdr-ground` | **Лабораторний джамер і аналізатор** — не вузол мережі |

N0 вже є і вже заведена — це означає, що стенд (11) можна будувати, не чекаючи
решти плат.
